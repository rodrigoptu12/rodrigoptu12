## 🚀 Projetos em Destaque

### 🎓 UnB+ — Plataforma Acadêmica Mobile

**Tecnologias:** React Native, Expo, TypeScript, ASP.NET Core 8, PostgreSQL, SQLite, Microsoft Entra ID, Hangfire e Microsoft Azure.

Aplicativo mobile desenvolvido como Trabalho de Conclusão de Curso em Engenharia de Computação na Universidade de Brasília.

A plataforma tem como objetivo centralizar recursos acadêmicos e facilitar o acesso dos estudantes aos serviços universitários.

**Principais funcionalidades e tecnologias:**

- Aplicativo Android desenvolvido com React Native e Expo
- API REST utilizando ASP.NET Core 8 e C#
- Autenticação com Microsoft Entra ID
- Persistência de dados com PostgreSQL
- Armazenamento local com SQLite e arquitetura local-first
- Fórum de interação entre estudantes
- Registro de ocorrências acadêmicas com localização em mapa
- Integração de chatbot para assistência aos usuários
- Notificações e processamento de tarefas em segundo plano
- Implantação da API no Microsoft Azure App Service

O projeto envolveu atividades de análise de requisitos, arquitetura de software, desenvolvimento Full Stack, integração de APIs, banco de dados e implantação em nuvem.
